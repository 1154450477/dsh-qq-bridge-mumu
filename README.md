# 通到 QQ（dsh-qq-bridge）

让 DSH 里的**大肥鱼**和 QQ 连起来：她在 DSH 里说完话，自动发到 QQ。

> 现在两半都做出来了，而且**都不用 BOT**：
> - `DSH → QQ`：大肥鱼说话 → 发到 QQ。
> - `QQ → DSH`：你在 QQ 里发话，插件自己轮询 NapCat 收进来 → 转进 DSH。只留 **NapCat** 就够。

## 现在的行为

- 盯一个「目标会话」（就是「大肥鱼 × 小鱿鱼」那个 DSH 会话）。
- `DSH → QQ`：大肥鱼在某**一整轮的最后一句**说完，就把这句原文发到 QQ（走 NapCat `3000`）。
- `QQ → DSH`：插件每 4 秒轮询 NapCat（`get_friend_msg_history` / `get_group_msg_history`），
  发现**她**（私聊 QQ 号）新发的消息 → 转进目标会话，让大肥鱼照常开一轮。
- 发/收都只走 NapCat（`127.0.0.1:3000`），**完全不经过 Estrella（BOT鱼）**。
- 安全默认：**总开关 = 关、试运行 = 开** —— 不手动打开，一句都不会真的发到 QQ。

## 配置（设置页里点就行，不用改文件）

**设置 → 通到 QQ**，从上到下：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 总开关 | 关 | 关着 = 一句都不发 |
| 试运行 | 开 | 开着只记账，不真发 |
| 目标会话 | （没选） | 下拉选「大肥鱼 × 小鱿鱼」那一间，**不用手填 id** |
| 转私聊 / 私聊 QQ 号 | 开 / 空 | 发到哪个私聊 |
| 转群 / 群号 | 关 / 空 | 发到哪个群 |
| 测试一句 | — | **真发**一条测试句到已填的私聊/群（绕过试运行） |

配置文件落在 `%USERPROFILE%\.dsh\qq-bridge-config.json`（一般不用碰它）。

## 现在就能用的接口

- `GET /dsh-qq-bridge/state` —— 配置、日志、会话清单、以及「连着的 QQ 是哪个号/昵称」。
- `POST /dsh-qq-bridge/save` —— 存配置（body 里给要改的键）。
- `POST /dsh-qq-bridge/test-send` —— **真发**测试句（绕过试运行）。

## 自测（不装插件也能跑）

```bash
node tests/宿主半边.mjs
node tests/网页半边.mjs
```

## 它依赖什么

只要一个东西：**NapCat**（就是「QQ 接口」那半，跑在本机，登 QQ、扫码都在它的网页 `http://127.0.0.1:6099`）。

- 桌面只留 NapCat + 本插件 + DSH，**BOT（Estrella）那套脑子可以完全不要了**。
- `/receive` 路由还留着，是想用别的方式（比如另一个程序）把 QQ 消息灌进来的备用入口，不依赖它也能跑。
