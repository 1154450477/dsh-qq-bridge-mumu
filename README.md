# 通到 QQ（dsh-qq-bridge）

让 DSH 里的**大肥鱼**和 QQ 连起来：她在 DSH 里说完话，自动发到 QQ。

> 现在两半都做出来了：
> - `DSH → QQ`：大肥鱼说话 → 发到 QQ（**本插件自己就够**）。
> - `QQ → DSH`：你在 QQ 里回 → 转进 DSH 让她接着想（本插件的 `/receive` + **Estrella 那边开个开关**，见文末「怎么把 BOT 接上」）。

## 现在的行为

- 盯一个「目标会话」（就是「大肥鱼 × 小鱿鱼」那个 DSH 会话）。
- 大肥鱼在某**一整轮的最后一句**说完，就把这句原文发到 QQ。
- 发 QQ 走 **NapCat 的 OneBot HTTP**（`127.0.0.1:3000`），**不经过 Estrella（BOT鱼）**。
- 安全默认：**总开关 = 关、试运行 = 开** —— 不手动打开，一句都不会真的发到 QQ。

## 配置（设置页里点就行，不用改文件）

**设置 → 通到 QQ**，从上到下：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 总开关 | 关 | 关着 = 一句都不发 |
| 试运行 | 开 | 开着只记账，不真发 |
| 目标会话 | （没选） | 下拉选「大肥鱼 × 小鱿鱼」那一间，**不用手填 id** |
| 转私聊 / 私聊 QQ 号 | 开 / 空 | 发到哪个私聊 |
| 转群 / 群号 | 关 / 空 | 发到哪个群 |
| 测试一句 | — | **真发**一条测试句到已填的私聊/群（绕过试运行） |

配置文件落在 `%USERPROFILE%\.dsh\qq-bridge-config.json`（一般不用碰它）。

## 现在就能用的接口

- `GET /dsh-qq-bridge/state` —— 配置、日志、会话清单、以及「连着的 QQ 是哪个号/昵称」。
- `POST /dsh-qq-bridge/save` —— 存配置（body 里给要改的键）。
- `POST /dsh-qq-bridge/test-send` —— **真发**测试句（绕过试运行）。

## 怎么把 BOT 接上（QQ → DSH 这半）

这一半要动 **Estrella（BOT）** 一个开关（在它的 `config.json` 里，`custom.qqBridge`，默认**全关**，不动就完全不影响它）：

```jsonc
"qqBridge": {
  "enabled": true,                    // 总开关
  "dshUrl": "http://127.0.0.1:19387", // DSH 地址
  "herQQ": "3274796953",              // 只转发她的 QQ 号
  "private": true,                    // 私聊这条桥
  "group": false,                     // 群这条桥
  "groupId": ""                       // 群号（group=true 时填）
}
```

改完**重启 BOT**。之后：

- 她在桥接的私聊/群里发一句 → BOT **转发给 DSH 并闭嘴**（不再自己动脑回）。
- DSH 的大肥鱼接话、回完 → 这句再经**本插件的上半场**发回 QQ。
- 桥连不上（DSH 没开 / 没接）→ BOT **照常自己回**（桥断 ≠ 鱼哑）。
